# HintChorus — слой изоляции интерфейса для SCP:SL

**Позволяет незнакомым друг с другом плагинам делить один экран, не меняя ни строчки кода.**

> В игре есть ровно **один** канал подсказок, и побеждает тот, кто написал последним.
> HintChorus превращает этот единственный канал в **независимые слоты** — по одному на каждого
> вызывающего, — определяя вызывающего автоматически по стеку. Плагин, который просто вызывает
> `SendHint` / `SendBroadcast`, работает как есть и перестаёт затирать остальных.

> **15.0.0 (2026-11-23) — настоящий промежуточный слой UI и языковые пакеты**
>
> - **Настоящие языковые пакеты.** Весь runtime-интерфейс берётся из встроенных `en/zh/fr/ru/es` (по 193 ключей). Файл `configs/<port>/HintChorus/lang/<code>.lang` переопределяет любой ключ и добавляет любой язык; отсутствующие ключи откатываются построчно. `Hint lang reload` перезагружает на лету.
> - **Анатомия конвейера Hint.** [15.0-hint-internals.md](../15.0-hint-internals.md): `HintDisplay.Show` → `HintMessage`, двоичный формат, 20 параметров, 3 эффекта, `SuppressedReceivers`, чек-лист 15.0.
>
> Также включено (с 1.1.2):
>
> - **Новое: арбитр патчей (Patch Arbiter).** Пять точек удаления патчей в Harmony взяты под контроль. Если фреймворк очищает метод через `Unpatch All`, наши патчи восстанавливаются в том же стеке вызовов и UI отправляется заново; щит раз в 0,25 с служит страховкой. Другие плагины по-прежнему могут выгружаться и патчить нормально.
> - **Новое: возврат по снимку (Snapshot Rollback & Takeover).** Подсказки сторонних плагинов сохраняются как снимки по игрокам до поглощения. Если другой hint-плагин изменяет канал после нас, HintChorus откатывает канал по снимку и заново перехватывает патч: либо выходя первым с максимальным приоритетом Harmony, либо через postfix-фолбэк, если наш префикс был пропущен.
> - **`Hint orvs`** определяет популярные hint-плагины: не найдено → вариант **1** = вернуть нативный вывод + воспроизвести данные; найдено → нумерованный список с горячим применением последних данных.
> - Подробный журнал по умолчанию выключен; обычный журнал — события и исключения.
>
> Если что-то пошло не так: `Hint orvs native`, или удалить HintChorus и перезапустить сервер.
> Целевая версия: текущая публичная ветка 14.2.x; точки патчей будут перепроверены после выхода 15.0 «Megapatch III».

> **Языковое примечание**: DLL содержит пять языковых пакетов (`en` / `zh` / `fr` / `ru` / `es`); любой другой язык добавляется через `configs/<port>/HintChorus/lang/<code>.lang`, с поочерёдным переопределением ключей и построчным откатом. См. [languages.md](../languages.md).

## Кратко / Подробно

- **Кратко**: HintChorus превращает единственный канал подсказок в изолированные слоты по вызывающему без изменения плагинов; включает арбитраж патчей, приоритетную загрузку `0.dll` и откат `Hint orvs`.
- **Подробно**: HintChorus — серверный слой изоляции UI для SCP:SL. Он перехватывает подсказки, broadcasts, консоль, CASSIE, админ-чат и хитмаркеры, определяет вызывающего и выделяет ему независимый слот. Арбитр патчей синхронно восстанавливает слой после внешней очистки; `0.dll` загружается раньше других плагинов; включены мастер первой настройки и безопасная проверка обновлений.
- **Первый запуск**: мастер в консоли сервера задаёт вопросы по одному (автообновление, подробный журнал, RNR, запись конфигурации) и показывает следующий только после ответа да/нет. Команды: `Hc setup`, `Hc setup да|нет`, `Hc setup <1-4> on|off`, `Hc setup done`, `Hc setup skip`. Только консоль сервера; в RA и другие места команда не регистрируется.

## Загрузка

**Достаточно одного файла**: основная DLL сама распаковывает свой загрузчик при первом запуске.

| | |
| --- | --- |
| Прямая загрузка (beta-сборка) | [`HintChorus.dll`](../../HintChorus.dll) |
| Страница релизов (рекомендуется) | [Releases](https://github.com/lll111III11/HintChorus/releases/latest) |

Начиная с Beta файлы релизов больше не содержат префикс `alpha-`: **имя сборки остаётся `HintChorus`**,
поэтому переименование файла ничего не ломает.

Установка:

1. Положите `HintChorus.dll` в `plugins/global/`
2. Запустите сервер (при первом запуске появится `0HintChorus.Bootstrap.dll` и потребуется один перезапуск — так задумано)
3. При необходимости измените `configs/<порт>/HintChorus/config.yml` (**ключи в snake_case**; см. [`docs/default-config.yml`](../default-config.yml))

## Что делает плагин

1. **Атрибуция** — перехватывает шесть точек входа интерфейса (подсказки / broadcast / консоль / CASSIE /
   чат администрации / маркер попадания) и по стеку вызовов определяет, **какой плагин и какая точка вызова** пишет.
2. **Детерминированный UiId** — `UUIDv5(поверхность | сборка | точка вызова | [смещение IL])`; не меняется после перезапуска.
3. **Один слот на UiId** — слияние, устойчивая сортировка по приоритету, вывод **единственным писателем**.
4. **Устойчивая раскладка** — см. ниже.

Плагинам **не нужно** менять код и ссылаться на этот плагин.

## Раскладка: почему позиции перестают прыгать

Блок подсказок **привязан к низу**, поэтому любое изменение высоты сдвигает все строки внутри.
Доступно два режима (`layout_mode`):

| Режим | Принцип | Компромисс |
| --- | --- | --- |
| **`rows`** (по умолчанию) | фиксированное число строк в изменчивой зоне + по одной строке на владельца, пустые строки дополняют | абсолютно стабильно, но занимает экран |
| **`offsets`** | пустых строк нет: каждая строка получает `<voffset>` и встаёт на своё место | так же стабильно **и** не занимает экран |
| `compact` | ничего не дополняется | самое компактное, но позиции меняются |

`offsets` использует **идею** **RueI (CC0)** — «не сетка и не строки, а вычисленное смещение» — с собственной
реализацией; высота строк измеряется встроенной таблицей метрик.
**Сторонний код не включён**: см. [`THIRD-PARTY.md`](../../THIRD-PARTY.md).

```yaml
layout_mode: rows        # переключите на offsets, чтобы не занимать экран
offset_row_height: 40    # высота одной строки в единицах voffset (весь экран ≈ 2140)
offset_sign: 1           # поставьте -1, если блок смещается в обратную сторону
offset_font_size: 20     # размер шрифта для измерения ширины текста
```

## Позиции: три синтаксиса в одном

В игре один канал подсказок, поэтому «позиция» в итоге — это `<voffset>` на строку.
HintChorus сводит источники к **сетке якорей 3×3** плюс **вертикальная шкала 0–1000**:

| Источник | Как записывается | Переключатель |
| --- | --- | --- |
| **① Совместимость с существующим** | текст уже несёт `<voffset>` / `<pos>` / `<align>` / `<line-height>` / `<indent>` / `<margin>` → **пропускается как есть** (не переупорядочивается и не выравнивается заново) | `honor_plugin_position_syntax` |
| **② Свой синтаксис · маркер** | `{{hc:top-right}}` или `{{hc:pos=750,align=left,offset=-90}}` — вырезается из текста, игрок его не видит | `enable_position_markers` |
| **③ Свой синтаксис · C# API** | `UiIsolation.SetHintPosition("MyPlugin", "pos=750,align=left")` — **тот же синтаксис**, что у маркера | — |
| **④ Автоматическая раскладка** | если ничего из этого нет, по имени — `exp` / `level` / `经验` → середина, на 90 ниже; `score` / `排行` → верх-право; `kill` / `击杀` → верх-лево; `timer` → верх-центр; `music` → низ-право | `auto_layout_by_plugin_name` |

**Приоритет разбора**: явный API → маркер → собственные теги плагина → таблица / имя → по умолчанию (низ-центр, естественная укладка).

> **Полная спецификация своего синтаксиса** (три измерения, грамматика, псевдонимы, примеры, FAQ):
> [`docs/position-spec.ru.txt`](../position-spec.ru.txt).

## Совместимость

- Поддерживаются оба стиля вызова — **LabAPI** и **EXILED**, без правок на стороне плагинов.
- Охваченные поверхности: подсказки / broadcast / консоль / CASSIE / чат администрации / маркер попадания /
  настройки сервера (SSS) / дисплей интеркома.
- Загрузка с `LoadPriority.Highest` и загрузчиком с префиксом `0`: патчи ставятся **раньше** остальных плагинов.
- **Языки**: встроенные подсказки игры переводятся **по языку каждого игрока** —
  в DLL встроены 5 языков ООН (`en` / `zh` / `fr` / `ru` / `es`) ; остальные языки клиента
  загружаются из папки `translations/` (официальные файлы лежат в
  [`docs/translations/`](../translations/)), при отсутствии строки — построчный откат на английский.

> Известный конфликт: фреймворк, который сам патчит вывод подсказок, используется **вместо** этого плагина —
> обоим нужен один и тот же канал.
