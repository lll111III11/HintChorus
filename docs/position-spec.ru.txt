================================================================================
HintChorus — Спецификация собственного синтаксиса позиции, v1
================================================================================
Аудитория : авторы плагинов, которым нужно поместить текст в заданное место экрана
Рядом     : docs/api-guide.zh.txt | README.md «Позиции: три синтаксиса в одном»

Одной строкой: напишите короткий маркер или вызовите один метод — и текст
закреплён там, где вам нужно.

--------------------------------------------------------------------------------
0. Зачем вообще синтаксис
--------------------------------------------------------------------------------
В игре ровно один канал подсказок, поэтому текст всех плагинов склеивается в
одно сообщение. Кто первый и в какой строке — было совершенно неуправляемо;
это и есть корень проблемы «интерфейсы затирают друг друга / прыгают вверх-вниз,
когда плагинов много».
HintChorus превращает это в то, что можно *объявить*: вы указываете только
«где я хочу быть», остальное делает слой.

--------------------------------------------------------------------------------
1. Три измерения
--------------------------------------------------------------------------------
Позиция описывается тремя измерениями (последние два необязательны):

  Вертикаль        <- обязательно, выбрать одно из двух
      (1) якорь 3x3:   top-left | top | top-right
                       middle-left | middle | middle-right
                       bottom-left | bottom | bottom-right
      (2) шкала 0-1000: 0 = низ экрана, 500 = середина, 1000 = верх

  Горизонталь      <- необязательно; иначе выводится из столбца якоря
      align = left | center | right

  Точная подстройка <- необязательно
      offset = <число>   (единицы voffset, плюс = ВВЕРХ; весь экран ~ 2140)

--------------------------------------------------------------------------------
2. Два канала — один синтаксис
--------------------------------------------------------------------------------
Канал A — текстовый маркер (без зависимостей, работает без ссылки на этот плагин)
    Поставьте {{hc:...}} в любом месте текста. Слой вырезает весь маркер перед
    отправкой — игрок его никогда не увидит.

        player.ShowHint("{{hc:top-right}} Счёт 12");
        player.ShowHint("{{hc:pos=750,align=left,offset=-90}} цель");

Канал B — C# API (для тех, кто ссылается на этот плагин)
    using HintChorus.Core.Layout;

    UiIsolation.SetHintPosition("MyPlugin", HintAnchor.MiddleCenter, -90f);
    UiIsolation.SetHintPosition("MyPlugin", "pos=750,align=left");  // тот же синтаксис
    UiIsolation.ClearHintPosition("MyPlugin");                      // назад к авто

Оба канала разбирают *одну и ту же* строку, поэтому значение в конфиге плагина
может просто хранить эту строку — маркер, конфиг и код делят один синтаксис.

--------------------------------------------------------------------------------
3. Полный синтаксис
--------------------------------------------------------------------------------
    {{hc:<тело>}}      тело = элементы через ',' или ';', порядок любой, регистр не важен

  Элемент                  Значение                    Величина
  -----------------------  --------------------------  ---------------------------------
  <имя якоря>              (голое) якорь 3x3           top-right / middle / tr ...
  <число>                  (голое) шкала 0-1000        750
  pos=<якорь | число>      якорь или шкала             pos=top-right | pos=750
  anchor=<имя якоря>       якорь                       anchor=middle
  y=<число>                шкала                       y=500
  scale=<число>            шкала                       scale=1000
  offset=<число>           подстройка (плюс = вверх)   offset=-90
  voffset=<число>          то же, что offset           voffset=40
  align=<left/center/right> горизонтальное выравнивание align=left

  Псевдонимы якорей (выдержка):
      tl / tr / tc      ml / mr / mc      bl / br / bc
      top / bottom / middle
      (китайские псевдонимы тоже принимаются: 左上 / 右上 / 中部 / 右下 ...)
  Псевдонимы выравнивания:
      left | l | start          center | c | middle          right | r | end

--------------------------------------------------------------------------------
4. Примеры
--------------------------------------------------------------------------------
    {{hc:top-right}}                          правый верхний угол (по правому краю)
    {{hc:750}}                                высота 750 по шкале 0-1000
    {{hc:pos=750,align=left}}                 та же высота, но по левому краю
    {{hc:middle,offset=-90}}                  середина экрана, затем на 90 ниже
    {{hc:pos=500,offset=-90,align=center}}    шкала + подстройка + явное выравнивание
    {{hc:bc}}                                 низ-центр (совпадает с умолчанием)

    UiIsolation.SetHintPosition("LevelHUD", "pos=500,offset=-90");

--------------------------------------------------------------------------------
5. Приоритет разбора (кто главнее)
--------------------------------------------------------------------------------
    (1) Явный API  (SetHintPosition)
    (2) Свой текстовый маркер  ({{hc:...}})
    (3) Собственные теги позиции плагина  (<voffset> / <pos> / <align> /
        <line-height> / <line-indent> / <indent> / <margin>) -> пропускаются как есть
    (4) Каталог / вывод функции по имени плагина
    (5) По умолчанию: низ-центр, естественная укладка

  Важно: как только сработал (3), слой полностью отпускает эту подсказку — он не
         трогает даже горизонтальное выравнивание. Именно поэтому интерфейсы из
         RueI / HintServiceMeow / сырого TMP остаются ровно на своих местах.

--------------------------------------------------------------------------------
6. Конфигурация
--------------------------------------------------------------------------------
  honor_plugin_position_syntax  (по умолчанию true)   включить (3)
  auto_layout_by_plugin_name    (по умолчанию true)   включить (4)
  enable_position_markers       (по умолчанию true)   распознавать и вырезать {{hc:...}}
  screen_height_units           (по умолчанию 2140)   сколько voffset в целом экране
  position_overrides            (по умолчанию пусто)  таблица владельца сервера, тот же синтаксис:

        position_overrides:
          LevelSystem: middle,offset=-90
          MyPlugin: pos=750,align=left

--------------------------------------------------------------------------------
7. Соответствие экосистеме
--------------------------------------------------------------------------------
  «Scaled position» RueI / ruei-cm-lab (0-1000)  ->  наш pos=<0-1000>, значение можно копировать
      их исходник: baseline = 755 - 2.14 * pos;  2.14 * 1000 = 2140 = наше умолчание
  XCoordinate / YCoordinate у HintServiceMeow   ->  его вывод несёт теги позиции,
                                                     обрабатывается через (3)
  Сырой TMP <voffset> / <pos> / <align> / ...    ->  обрабатывается через (3)

--------------------------------------------------------------------------------
8. Частые вопросы
--------------------------------------------------------------------------------
  В: Увидят ли игроки маркер?
  О: Нет. После разбора он вырезается; он появится только если выключить
     enable_position_markers (для диагностики).

  В: Конфликт с шаблонами {0} других фреймворков?
  О: Нет. Наш маркер — двойные фигурные скобки {{ }}, и он разбирается раньше шаблонов.

  В: Позиция верх / середина немного смещена.
  О: Подстройте screen_height_units (коэффициент всего экрана); либо уточните
     отдельные подсказки через offset.

  В: Несколько плагинов в одной позиции?
  О: Подсказки одной позиции устойчиво сортируются по приоритету и складываются
     вертикально; они не затирают друг друга.

  В: Переместить плагин, не трогая его код?
  О: Используйте position_overrides — ровно тот же синтаксис.

--------------------------------------------------------------------------------
9. Блокировка позиции (зафиксирована - больше не сдвигается)
--------------------------------------------------------------------------------
Позиция назначается ОДИН РАЗ, при первом появлении владельца - назначение и есть
"сортировка завершена". Далее:
  . появление/исчезновение других плагинов и изменение содержимого никогда не
    сдвигают уже размещённую строку;
  . строки внутри одной зоны занимают места с ФИКСИРОВАННОЙ ВЫСОТОЙ по порядку,
    а не "плавают" по высоте содержимого.

Как: размещение считается только по ЗАБЛОКИРОВАННОМУ НОМЕРУ СТРОКИ владельца,
зона привязана лишь к своей строке 0 - и никак не зависит от того, сколько строк
в ней сейчас. Плагины без объявленной позиции не блокируются: у них остаётся
естественная укладка снизу, поэтому привычный вид не меняется.
