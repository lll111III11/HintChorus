# HintChorus — слой изоляции интерфейса для SCP:SL

**Позволяет незнакомым друг с другом плагинам делить один экран, не меняя ни строчки кода.**

> В игре есть ровно **один** канал подсказок, и побеждает тот, кто написал последним.
> HintChorus превращает этот единственный канал в **независимые слоты** — по одному на каждого
> вызывающего, — определяя вызывающего автоматически по стеку. Плагин, который просто вызывает
> `SendHint` / `SendBroadcast`, работает как есть и перестаёт затирать остальных.

## Загрузка

**Достаточно одного файла**: основная DLL сама распаковывает свой загрузчик при первом запуске.

| | |
| --- | --- |
| Прямая загрузка (имя файла содержит префикс `alpha-`) | [`alpha-HintChorus.dll`](../../alpha-HintChorus.dll) |
| Страница релизов (рекомендуется) | [Releases](https://github.com/lll111III11/HintChorus/releases/latest) |

Префикс `alpha-` обозначает лишь этап разработки: **имя сборки остаётся `HintChorus`**,
поэтому переименование файла ничего не ломает.

Установка:

1. Положите `alpha-HintChorus.dll` в `plugins/global/`
2. Запустите сервер (при первом запуске появится `0HintChorus.Bootstrap.dll` и потребуется один перезапуск — так задумано)
3. При необходимости измените `configs/<порт>/HintChorus/config.yml` (**ключи в snake_case**; см. [`docs/default-config.yml`](../default-config.yml))

## Что делает плагин

1. **Атрибуция** — перехватывает шесть точек входа интерфейса (подсказки / broadcast / консоль / CASSIE /
   чат администрации / маркер попадания) и по стеку вызовов определяет, **какой плагин и какая точка вызова** пишет.
2. **Детерминированный UiId** — `UUIDv5(поверхность | сборка | точка вызова | [смещение IL])`; не меняется после перезапуска.
3. **Один слот на UiId** — слияние, устойчивая сортировка по приоритету, вывод **единственным писателем**.
4. **Устойчивая раскладка** — см. ниже.

Плагинам **не нужно** менять код и ссылаться на этот плагин.

## Раскладка: почему позиции перестают прыгать

Блок подсказок **привязан к низу**, поэтому любое изменение высоты сдвигает все строки внутри.
Доступно два режима (`layout_mode`):

| Режим | Принцип | Компромисс |
| --- | --- | --- |
| **`rows`** (по умолчанию) | фиксированное число строк в изменчивой зоне + по одной строке на владельца, пустые строки дополняют | абсолютно стабильно, но занимает экран |
| **`offsets`** | пустых строк нет: каждая строка получает `<voffset>` и встаёт на своё место | так же стабильно **и** не занимает экран |
| `compact` | ничего не дополняется | самое компактное, но позиции меняются |

`offsets` использует **идею** **RueI (CC0)** — «не сетка и не строки, а вычисленное смещение» — с собственной
реализацией; высота строк измеряется встроенной таблицей метрик.
**Сторонний код не включён**: см. [`THIRD-PARTY.md`](../../THIRD-PARTY.md).

```yaml
layout_mode: rows        # переключите на offsets, чтобы не занимать экран
offset_row_height: 40    # высота одной строки в единицах voffset (весь экран ≈ 2140)
offset_sign: 1           # поставьте -1, если блок смещается в обратную сторону
offset_font_size: 20     # размер шрифта для измерения ширины текста
```

## Совместимость

- Поддерживаются оба стиля вызова — **LabAPI** и **EXILED**, без правок на стороне плагинов.
- Охваченные поверхности: подсказки / broadcast / консоль / CASSIE / чат администрации / маркер попадания /
  настройки сервера (SSS) / дисплей интеркома.
- Загрузка с `LoadPriority.Highest` и загрузчиком с префиксом `0`: патчи ставятся **раньше** остальных плагинов.
- **Языки**: встроенные подсказки игры переводятся **по языку каждого игрока** —
  в DLL встроены 5 языков ООН (`en` / `zh` / `fr` / `ru` / `es`) ; остальные языки клиента
  загружаются из папки `translations/` (официальные файлы лежат в
  [`docs/translations/`](../translations/)), при отсутствии строки — построчный откат на английский.

> Известный конфликт: фреймворк, который сам патчит вывод подсказок, используется **вместо** этого плагина —
> обоим нужен один и тот же канал.
